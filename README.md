# ImmigrationAnalyzer

**ImmigrationAnalyzer** is an AI-assisted, self-assessment tool designed to help international professionals evaluate their eligibility for U.S. self-petition green card categories — **EB1-A (Extraordinary Ability)** and **EB2-NIW (National Interest Waiver)**.

This tool provides a personalized profile assessment, scoring dashboard, and checklist builder to guide users through the early stages of their self-petition journey.

---

## ✨ Features

- ✅ EB1-A and EB2-NIW eligibility quiz based on USCIS criteria  
- 📊 Interactive radar chart visualizing profile strengths  
- 🗂 Personalized checklist for petition evidence  
- 💬 Clean UI with custom styling for professional users  
- 💡 Built with Streamlit for fast deployment and iteration
